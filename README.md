# Free Text Formatting Tool

A simple, lightweight, browser-based tool for cleaning and formatting messy text.

It helps remove unnecessary spaces, clean up excessive line breaks, and make copied text easier to read and reuse.

## ✨ Features

* Remove extra spaces
* Clean unnecessary blank lines
* Fix messy copied text
* Copy formatted text with one click
* Works directly in the browser
* No installation required
* No external libraries or dependencies

## 🚀 Live Demo

You can use the online demo through GitHub Pages after enabling it for this repository.

## 🛠️ How to Use

1. Open the text formatting tool.
2. Paste your messy text into the input box.
3. Click **Format Text**.
4. Review the cleaned result.
5. Click **Copy Formatted Text**.
6. Paste the result wherever you need it.

## 💡 Why Use a Text Formatting Tool?

Text copied from websites, PDFs, emails, documents, and other applications can sometimes contain unwanted spaces and excessive line breaks.

A simple formatting tool can quickly clean this content before using it in:

* Documents
* Emails
* Blog posts
* Social media
* AI prompts
* Notes
* Code comments
* Other online tools
